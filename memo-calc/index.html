プライバシーポリシー

「計算結果を残して使えるメモ電卓」（以下「本アプリ」。iPhone・iPad 版と Android 版）における利用者の情報の取り扱いについて説明します。

1. 運営者

Studio Beita

2. 本アプリが取得する情報

本アプリは、氏名・メールアドレス・電話番号などの個人情報を取得しません。アカウント登録もありません。

保存したメモ（名前と数字）と設定（見た目・言語・税率など）は、利用者の端末の中にのみ保存され、運営者を含む外部へ送信されることはありません。アプリを削除すると、これらのデータも削除されます（「広告を消す」の購入は、設定の「購入を復元」で元に戻せます）。

3. アプリ内課金について

本アプリには、画面の下の広告を消す買い切りの商品「広告を消す」があります。支払いの手続きは、iPhone・iPad 版では Apple（App Store）、Android 版では Google（Google Play）が行います。運営者が、クレジットカードの番号などの支払いの情報を受け取ることはありません。

本アプリは、購入済みかどうかを確かめるために、ストア（App Store・Google Play）から購入の記録（商品の種類・購入日時・取引の番号など）を受け取り、端末の中で使います。この記録を運営者に送ることはありません。

4. 広告について

本アプリは、Google LLC が提供する広告配信サービス「Google AdMob」を利用しています。広告の配信・効果測定・不正防止のため、AdMob は次のような情報を取得することがあります。

  • 広告識別子などの端末の識別子（iPhone・iPad 版：IDFA。利用者がトラッキングを許可した場合のみ／Android 版：広告 ID）
  • IP アドレスから推定されるおおよその位置情報
  • 広告の表示・操作に関する情報、端末の種類や OS などの情報
  • クラッシュやパフォーマンスに関する診断情報

iPhone・iPad 版：トラッキングの許可は、初めて起動したとき（使い方ガイドを閉じたあと）に表示される確認画面で選択でき、後から iPhone・iPad の「設定」→「プライバシーとセキュリティ」→「トラッキング」でいつでも変更できます。

Android 版：広告 ID は、端末の「設定」→「Google」→「広告」（機種によっては「設定」→「プライバシー」→「広告」）で、いつでもリセットまたは削除できます。削除すると、利用者に合わせた広告は表示されなくなります。

トラッキングを許可しない場合や広告 ID を削除した場合も、広告の内容が利用者に合わせたものでなくなるだけで、本アプリの機能はすべて使えます。

英国などでは、法令に基づく同意の確認画面が表示されることがあります。その場合、同意の内容は、本アプリの設定の「広告」→「プライバシー設定（広告の同意）」から変更できます。

「広告を消す」を購入すると、広告は表示されなくなります。

Google による情報の取り扱いについては、次のページをご確認ください。

  • Google プライバシーポリシー
  • Google のサービスを使用するサイトやアプリから収集した情報の Google による使用

5. 第三者への提供

運営者は、利用者の情報を第三者に提供しません（上記のストアと広告サービスが自ら取得する情報を除きます）。
